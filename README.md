# 🎯 QuizHub – AI Powered Quiz Platform

QuizHub is a modern and interactive web-based quiz platform that allows users to create quizzes, participate in quizzes, and generate AI-based quizzes dynamically.

It is designed with a clean UI, responsive layout, and engaging quiz experience including timers, scoring, and quiz management features.

---

# 🚀 Features

✅ Participate in interactive quizzes  
✅ Create custom quizzes easily  
✅ AI-powered quiz generation  
✅ Timer-based quiz system  
✅ Instant score calculation  
✅ Clean and modern responsive UI  
✅ Simple and user-friendly interface

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/QuizHub.git
```

---

## 2️⃣ Move Project to XAMPP htdocs

Copy the project folder into:

```bash
C:\xampp\htdocs\
```

---

## 3️⃣ Start Apache & MySQL

Open XAMPP Control Panel and start:

- Apache
- MySQL

---

## 4️⃣ Import Database

1. Open phpMyAdmin
2. Create a database named:

```sql
quiz_db
```

3. Import the SQL file.

---

## 5️⃣ Run the Project

Open browser:

```bash
http://localhost/QuizHub/
```
